## Scoring policy

Coding composite = 45% external-checker correctness + 35% clean completion + 20% min-max normalized speed across the four shared OpenBench tasks. The all-around matrix uses coding 35%, speed 15%, context 15%, long-running 15%, tool use 10%, and recovery 10%; it publishes only when every candidate has every required dimension.
